## The entry

> Lovely planet, but the locals drink another species' baby milk as adults and call it normal. 4/5, would abduct again.

## How it works

`main.ts` (TypeScript, Node 22) writes the single review line to
`/output/entry.txt`, guarded to 1–200 UTF-8 characters, one line, no newline:

```sh
node main.ts
cat /output/entry.txt
```
